# Выпускная квалификационная работа магистра
## Разработка программы расчета и визуализации двумерного нестационарного течения многокомпонентного газа в сопле жидкостного ракетного двигателя


Студент: К. И. Журавлев

Научный руководитель: В. Ю. Гидаспов

<hr/>

Репозиторий будет содержать все части ВКР, а именно: исходный код, отчет, презентацию.

Цель работы - разработка и исследование программных методов расчета нестационарных многокомпонентных реагирующих течений с ударными и детонационными волнами.

Для достижения указанной цели были поставлены и решены следующие задачи:
1) сформулировать математическую модель многокомпонентного реагирующего газа;
2) исследовать существующие CFD-пакеты и выбрать базовую вычислительную платформу;
3) реализовать и верифицировать одномерную задачу детонации за отраженной ударной волной;
4) перейти к двумерному моделированию и исследовать ячеистую структуру детонации;
5) провести расчеты для смесей 𝐻_2 |𝑂_2 | 𝑁_2  и 𝐶𝐻_4 |𝑂_2 | 𝑁_2
6) реализовать визуализацию и параллельное выполнение расчетов


В работе применялись следующие инструменты:
1) язык программирования Python, С++/OpenFoam;
2) библиотеки научных вычислений NumPy, SDToolBox, Cantera;
3) библиотеки построения графиков Matplotlib и Seaborn;
4) среда разработки Jupyter.

В качестве основных результатов работы можно выделить:
1) верифицированная одномерная модель отраженной ударной волны и детонации;
2) получение параметров двумерных течений, положение фронтов ударных и детонационных волн, x-t диаграммы распространения волн;
3) сравнение параметров для различных горючих смесей.
